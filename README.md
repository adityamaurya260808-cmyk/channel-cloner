# channel-cloner

- [`extension/`](extension/): **FlowPilot**, a Chrome extension for batch prompts and auto-download on Google Flow.
  See [extension/README.md](extension/README.md) for install and usage.
- [`web/`](web/): a demo page and `flowpilot-client.js`, for generating with Flow from your own website
  through FlowPilot. See "Use from your own website" in the extension README.
